# 21/08/2026  Quiz
## Solucion Quiz
1.**Que es RPAS:**   Por lo que entendi de las clases es que es la que se encarga de enlazar algunas antenas para no perder comunicacion con las uas a grandes distancias y evitar la pérdida de comunicación.
2.**Que es RC:** Es el radiocontrol, pues el encargado de permitir al operador controlar el UAS.
3.**Que es VLOS:**  Es mantener contacto visual directo con el UAS durante el vuelo.
4.**Que es EVLOS:** Es tener un observador, en la operación para mantener vigilancia visual del UAS.
5.**Que es BVLOS** Si mal no estoy no era necesario el contacto visual con el UAS pero por el uso de los sensores (camaras) del mismo. /n
6.**Que es NOTAM:** Es un acuerdo en el que en zonas controladas se comunican con el operador de UAS por restricciones o condiciones especiales.

7.**A,B,C,D,E:**  Sinceramente recuerdo es **la g que era para no controladas**, las demas son zonas controladas osea que hay algun tipo de supervision o tenia algun control de tránsito aéreo.

8.**Que es OACI**   Organización de Aviación Civil Internacional osea es encargada de poner las normas internacionales para garantizar la seguridad y buena practica de la aviación civil.
